# Artwork and generation notes

Created with the built-in image generation tool for the approved Cinematic Manga Studio mock-ups. Final project assets are local WebP files and ship with the static site. Original generated PNGs remain separate from the source repository. Format conversion and sizing optimize web delivery; character transparency is preserved.

| Final path | Purpose | Final generation prompt |
| --- | --- | --- |
| `dist/assets/worlds.webp` | Six-theme photo sprite | Six flush equal cells in a 3-by-2 grid: an Istanbul-inspired home at dusk, airport travel, laptop and headphones, library study, a purple alpine lake, and warm night-market food. Cinematic navy/violet grading and amber/coral highlights. No text, UI, green, teal or logos. Each cell has a recognizable central subject. |
| `dist/assets/city.webp` | Home theme and hub background | Cinematic Istanbul-inspired residential rooftops at blue hour, warm apartment windows, distant towers and violet sunset sky. Realistic photography, dim exposure, detail around the edges. No people, text, logos, green or teal. |
| `dist/assets/mentor-boy.webp` | Question/planning/layout illustration | Recreate the original boy from the approved planning mock-up: tousled black hair, coral hoodie and navy trousers, seated thoughtful pose with cheek on hand. Contemporary inked manga and restrained halftone shading. Hair to knees inside frame. Transparent background; no text, speech bubble, UI or white border. |
| `dist/assets/mentor-girl.webp` | Hub/speaking/review illustration | Recreate the original girl from the approved speaking mock-up: dark hair in a loose bun, blue jacket over a pale hoodie, navy trousers and an encouraging relaxed pose. Contemporary inked manga and restrained halftone shading. Hair to knees inside frame. Transparent background; no text, speech bubble, UI or white border. |

The hourglass, moving sand, progress orbit, spidergram connectors and interface icons are native HTML/CSS/SVG so they remain connected to real timer and plan state rather than being flattened into an image.
